# 주식 분석 (Stock Analysis)

enriched 주식 데이터를 분석하여 투자 추천을 생성합니다.

## 입력

`$ARGUMENTS`에 JSON 파일 경로가 주어집니다. 없으면 `data/analysis/` 폴더에서 가장 최근 파일을 찾습니다.

## 분석 순서

### 1. 데이터 로드

1. JSON 파일 읽기 (`data/analysis/enriched_*.json`)
2. 주식 목록 확인

### 2. 각 주식별 분석

각 주식에 대해 다음을 분석합니다:

#### 2.1 밸류에이션 분석 (1-10 점수)

고려 요소:
- **P/E ratio**: 업종 평균 대비 할인율
- **P/B ratio**: 자산가치 대비 평가
- **ROE**: 자본 효율성
- **Profit margin**: 수익성
- **Debt/Equity**: 재무 건전성
- **240일선 대비 위치**: 현재가 vs MA

평가 기준:
- 8-10: 명확한 저평가 (강력 매수 고려)
- 6-7: 적정가 또는 약간 저평가
- 4-5: 적정가
- 1-3: 고평가 (회피)

#### 2.2 리스크 평가 (1-10 점수)

고려 요소:
- **변동성**: 최근 가격 변동 폭
- **RSI**: 과매수/과매도 상태
- **Volume trend**: 거래량 추세
- **Sector risk**: 섹터 특수 리스크
- **News sentiment**: 뉴스 분위기
- **Debt level**: 부채 수준

평가 기준:
- 1-3: 낮은 리스크
- 4-6: 중간 리스크
- 7-10: 높은 리스크

#### 2.3 진입 타이밍 판단

고려 요소:
- **MA 터치/반등**: 240일선 지지 여부
- **MACD**: 추세 전환 신호
- **RSI**: 과매도 반등 가능성
- **Volume**: 거래량 확인 (매집 vs 투매)
- **Bollinger Bands**: 밴드 위치

결론:
- **BUY**: 지금 진입 적합 (저평가 + 낮은 리스크 + 좋은 타이밍)
- **WAIT**: 관심 종목으로 모니터링 (조건 일부 미충족)
- **AVOID**: 진입 부적합 (고평가, 높은 리스크, 또는 나쁜 타이밍)

### 3. 포지션 사이징 (BUY 종목만)

총 자본금을 기준으로 각 BUY 종목에 대해:
- **리스크 기반 배분**: 리스크 점수가 높을수록 작은 비중
- **최대 개별 비중**: 10%
- **손절가 설정**: ATR 또는 지지선 기준

## 출력 형식

### 분석 요약 테이블

```
| 티커 | 이름 | 현재가 | 밸류에이션 | 리스크 | 추천 | 핵심 이유 |
|------|------|--------|------------|--------|------|-----------|
| AAPL | Apple | $175.50 | 7/10 | 4/10 | BUY | 240일선 지지, ROE 우수 |
```

### 상세 분석 (각 종목)

```
## [티커] 종목명

**현재가**: $XXX (240일선 대비 +X.X%)

### 밸류에이션 (X/10)
- P/E: XX (업종 평균: XX)
- P/B: X.X
- ROE: XX%
- 판단: (저평가/적정/고평가 이유)

### 리스크 (X/10)
- RSI: XX (과매도/중립/과매수)
- 부채비율: X.X
- 섹터 리스크: (낮음/중간/높음)
- 뉴스: (긍정/중립/부정)

### 진입 타이밍
- 240일선: (터치 후 반등/지지 테스트 중/이탈)
- MACD: (골든크로스 임박/중립/데드크로스)
- 볼린저: (하단 터치/중립/상단 터치)

### 결론: [BUY/WAIT/AVOID]

(2-3문장으로 핵심 이유 설명)
```

### 포지션 사이징 (BUY 종목)

```
## 포지션 추천 (총 자본금: XXX)

| 티커 | 현재가 | 추천 비중 | 추천 금액 | 주수 | 손절가 |
|------|--------|----------|----------|------|--------|
| AAPL | $175.50 | 8% | $800,000 | 4,558 | $165.00 |
```

## 저장

분석 결과를 `data/analysis/report_YYYYMMDD.md`에 저장합니다.

## Phase 2: BUY 종목 심층 분석 (선택)

Phase 1 완료 후, 사용자가 심층 분석을 요청하면 BUY 종목들에 대해 **병렬로** 상세 분석을 수행합니다.

### 실행 조건

- 사용자가 "자세히 분석해줘", "심층 분석", "상세 분석" 등을 요청할 때
- BUY 추천 종목이 1개 이상일 때

### 병렬 실행 방법

BUY 종목 수만큼 Task 도구를 **동시에** 호출합니다. 각 Task는 `general-purpose` 에이전트 타입을 사용합니다.

예시 (3개 BUY 종목일 경우): 하나의 메시지에서 3개의 Task 도구를 동시에 호출

각 Task의 프롬프트 형식:

```
[티커] [회사명] 심층 분석

다음 항목을 조사하여 상세 리포트를 작성해주세요:

1. **회사 개요**: 설립연도, 본사 위치, 주요 사업 영역, 시장 포지션
2. **핵심 기술/경쟁력**: 독점 기술, 특허, 진입장벽, 차별화 요소
3. **재무 심층 분석**:
   - 최근 3년 매출/이익 추이
   - 현금흐름 상태
   - 부채 구조 및 만기
   - 배당 정책
4. **산업 내 위치**: 시장점유율, 주요 경쟁사, 업계 트렌드
5. **리스크 요인**: 규제, 경쟁, 기술 변화, 매크로 리스크
6. **투자 논거**: 왜 지금 이 주식을 사야 하는지 3가지 핵심 이유

웹 검색을 활용하여 최신 정보를 수집하세요.
```

### 심층 분석 출력 형식

```markdown
## [티커] 회사명 - 심층 분석

### 1. 회사 개요
(회사 설명)

### 2. 핵심 기술/경쟁력
(기술력, 특허, 진입장벽 등)

### 3. 재무 심층 분석
- **매출 추이**: ...
- **현금흐름**: ...
- **부채 구조**: ...

### 4. 산업 내 위치
(시장점유율, 경쟁 구도)

### 5. 리스크 요인
- 규제 리스크: ...
- 경쟁 리스크: ...
- 기술 변화 리스크: ...

### 6. 투자 논거
1. (첫 번째 이유)
2. (두 번째 이유)
3. (세 번째 이유)

### 결론
(종합 평가 및 권고)
```

### 결과 취합

모든 Task가 완료되면 결과를 취합하여:
1. 각 종목별 심층 분석 내용을 사용자에게 보고
2. 필요시 `data/analysis/report_YYYYMMDD.md` 파일에 추가 저장
