# [Macro] 금리/채권 지표 추가 (국채 금리, 한미 금리차, 신용 스프레드)

- **날짜**: 2026-03-11
- **이슈**: https://github.com/foxyberry/quant-investment/issues/1176
- **브랜치**: `feature/issue1176`
- **상태**: 진행중

## 목표

매크로 모니터에 금리/채권 섹션을 추가하여 국채 금리(US 10Y, KR 10Y), 한미 금리차, 신용 스프레드(US HY OAS)를 실시간 표시한다.

## 배경

현재 매크로 모니터는 FX(USD/KRW), 선물(KODEX 200), 투자자 수급 3축으로 구성되어 있다. 금리/유동성은 매크로 판단의 핵심이지만 현재 모니터에 없어 별도 확인이 필요하다.

## 데이터 소스 분석

### yfinance (우선순위 1 — 이미 프로젝트에 설치됨)
| 지표 | 티커 | 비고 |
|------|------|------|
| US 10Y | `^TNX` | 실시간, 무료 |
| US 2Y | `^IRX` (13주 TB) 또는 `2YY=F` | 2Y 직접 티커 불안정, FRED 보완 |
| US 2-10 스프레드 | `^TNX - ^IRX` 계산 | |

### FRED API (우선순위 1 — 무료, 일 500건)
| 지표 | Series ID | 비고 |
|------|-----------|------|
| US 10Y | `DGS10` | 일별, 장 마감 후 갱신 |
| US 2Y | `DGS2` | 일별 |
| US HY OAS | `BAMLH0A0HYM2` | 일별, ICE BofA High Yield |
| US 2-10 스프레드 | `T10Y2Y` | 직접 제공 |

### 한국은행 ECOS API (우선순위 2 — 무료)
| 지표 | 통계표 | 비고 |
|------|--------|------|
| KR 국고채 3Y | 통계표코드 `817Y002` / 항목 `010200000` | 일별 |
| KR 국고채 10Y | 통계표코드 `817Y002` / 항목 `010210000` | 일별 |

### 계산 지표
| 지표 | 산출 | 의미 |
|------|------|------|
| US 2-10 스프레드 | US 10Y - US 2Y | 역전 = 경기침체 신호 |
| 한미 금리차 (10Y) | KR 10Y - US 10Y | 음수 확대 = 자본 유출 압력 |

## 구현 범위 (Phase 분리)

### Phase 1 (이번 PR) — Acceptance Criteria 충족
- US 10Y, KR 10Y, 한미 금리차, US 2-10 스프레드 표시
- yfinance(US) + FRED fallback + ECOS(KR)
- 매크로 페이지에 "금리/채권" 섹션 추가
- i18n (en/ko/zh)

### Phase 2 (후속 이슈)
- 신용 스프레드 (US HY OAS, KR CDS 등)
- 매크로 점수에 금리 컴포넌트 통합 (4번째 축)
- 금리 히스토리 차트

## 기술적 고려사항

### 데이터 가용성
- **yfinance `^TNX`**: 장중 실시간, 장외 마지막 값 유지. 불안정할 수 있어 FRED fallback 필수
- **FRED**: 일 1회 갱신 (전일 마감 기준). API key 필요 (`FRED_API_KEY`)
- **ECOS**: 일 1회 갱신. API key 필요 (`ECOS_API_KEY`)
- API key 없으면 해당 소스 graceful skip (null 반환, 에러 아님)

### 캐시 전략
- yfinance: 5분 TTL (실시간성)
- FRED/ECOS: 1시간 TTL (일별 데이터이므로)
- 프론트: React Query staleTime 2분, refetchInterval 60초

### 기존 매크로 점수에 미치는 영향
- Phase 1에서는 금리를 표시만 하고 매크로 점수 계산에는 포함하지 않음
- Phase 2에서 4번째 축으로 통합 검토

### 병렬 실행 계획
- **서버팀 (Codex)**: fred_service.py, ecos_service.py, bond_rate_service.py, 스키마, 라우터
- **프론트팀 (Codex)**: 타입, API 클라이언트, 훅, 페이지 UI, i18n
- **리드**: 계획 조율, 코드 리뷰, 통합, Git
