# [Macro] 글로벌 매크로 지표 추가 (DXY, 원자재, MSCI EM/DM)

- **날짜**: 2026-03-11
- **이슈**: https://github.com/foxyberry/quant-investment/issues/1178
- **브랜치**: `feature/issue1178`
- **상태**: 계획중

## 목표

매크로 모니터에 글로벌 크로스에셋 지표 섹션을 추가하여 DXY(달러 인덱스), 원자재(WTI, 금, 구리), MSCI(EM/DM) 데이터를 실시간 표시한다.

## 배경

현재 매크로 모니터는 KRW FX, 선물, 투자자 수급, 금리, 변동성 5개 축으로 구성되어 있다. 글로벌 리스크온/오프 판단을 위한 크로스에셋 지표(달러, 원자재, 신흥국/선진국 주식)가 없어 시장 전체 그림을 파악하기 어렵다.

## 데이터 소스

모두 yfinance로 무료 수집 가능 (기존 프로젝트에 설치됨).

| 지표 | 티커 | 설명 |
|------|------|------|
| DXY (달러 인덱스) | `DX-Y.NYB` | 달러 강세/약세 → 신흥국 자본 흐름 |
| WTI 원유 | `CL=F` | 인플레이션/에너지 리스크 |
| 금 | `GC=F` | 안전자산 수요 |
| 구리 | `HG=F` | 경기 선행 지표 ("Dr. Copper") |
| MSCI EM ETF | `EEM` | 신흥국 위험선호 |
| MSCI DM ETF | `EFA` | 선진국 위험선호 |

## 구현 범위 (Phase 1)

### Backend

1. **`api/services/global_macro_service.py` 신규**
   - `GlobalMacroService` 클래스
   - `get_snapshot() -> Dict[str, Any]`
   - 각 티커별 `_fetch_ticker(symbol)` → (value, change_pct, as_of) 패턴
   - yfinance `fast_info['lastPrice']` primary, `history(period='2d')` fallback (VIX 패턴 동일)
   - EM/DM ratio 계산: `EEM close / EFA close`
   - TTL 캐시: 장중 5분, 장외 30분 (VolatilityService 패턴)
   - 싱글톤 패턴
   - vix/vkospi와 다르게 모두 같은 소스(yfinance)이므로 하나의 서비스에 통합

2. **`api/schemas/market.py` 수정**
   - `MacroGlobalSnapshot` 스키마 추가:
     - dxy, dxy_change_pct, dxy_as_of
     - wti, wti_change_pct, wti_as_of
     - gold, gold_change_pct, gold_as_of
     - copper, copper_change_pct, copper_as_of
     - msci_em, msci_em_change_pct, msci_em_as_of
     - msci_dm, msci_dm_change_pct, msci_dm_as_of
     - em_dm_ratio (계산값)
   - `MacroBundleResponse`에 `global_macro: Optional[MacroGlobalSnapshot]` 추가

3. **`api/routers/market.py` 수정**
   - `get_macro_bundle()`에서 global_macro_service 연결 (bonds/volatility 패턴 동일)

### Frontend

4. **`web/src/lib/types.ts` 수정**
   - `MacroGlobalSnapshot` 인터페이스
   - `MacroBundle`에 `global_macro` 필드

5. **`web/src/app/[locale]/macro/page.tsx` 수정**
   - 변동성 섹션 아래에 "글로벌 지표" 섹션 추가
   - 3x2 MetricCard 그리드:
     - DXY (달러 인덱스)
     - WTI 원유
     - 금
     - 구리
     - MSCI EM
     - MSCI DM
   - EM/DM ratio를 MSCI EM 카드의 sub-item으로 표시

6. **i18n** — en/ko/zh

### 테스트

7. `api/tests/test_global_macro_service.py` — 스냅샷, null-safe, EM/DM 비율

## 기술적 고려사항

- 6개 티커를 순차 호출하면 느릴 수 있음 → `ThreadPoolExecutor`로 병렬 fetch 고려
- yfinance `fast_info`는 일부 선물 티커에서 불안정할 수 있음 → history fallback 필수
- DXY `DX-Y.NYB`는 yfinance에서 간헐적으로 실패 → graceful None 처리
- US 장 기준 데이터이므로 DST-aware market hours 적용 (volatility_service 패턴)
- EM/DM ratio는 두 값 모두 있을 때만 계산
