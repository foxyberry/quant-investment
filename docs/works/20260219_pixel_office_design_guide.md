# 디자인 가이드: 픽셀 캐릭터의 픽셀 오피스

## 1. 목표

이 가이드는 "귀여운 픽셀"보다 **운영 가시성**을 우선한다.

1. 누가 일하는지 즉시 보일 것
2. 어느 레포가 실제로 돌아가는지 구분될 것
3. 상태 변화(작업/대기/실패)가 1초 안에 인지될 것

---

## 2. 아트 디렉션

## 톤

1. 16-bit 오피스 RPG + Gather Town 느낌
2. 과한 네온/글로우보다 선명한 대비
3. 배경은 차분, 상태표시는 강하게

## 구성

1. 상단 HUD: 운영 요약
2. 중앙 맵: 팀별 좌석/복도/회의실
3. 하단 패널: Runtime, Commands, Commits

---

## 3. 컬러 시스템

## 상태 색상 (고정)

1. Active: `#22c55e`
2. Working: `#f59e0b`
3. Waiting Input: `#38bdf8`
4. Idle: `#6b7280`
5. Sleeping: `#374151`
6. Failed/Error: `#f87171`

## 오피스 팔레트

1. 벽/창문: `#d9e3f2`, `#b8dcff`
2. 바닥: `#6d7d98`, `#73839f`
3. 책상/존: `#2f3e57`, `#3d4f6b`
4. 경계선: `#0f172a`, `#334155`

---

## 4. 픽셀 캐릭터 규칙

## 기본 크기

1. Avatar: `44x44`
2. Workstation: `44x12`
3. Chair: `18x6`

## 상태 표현 우선순위

1. 상태 링(필수)
2. 상태 칩 텍스트(필수)
3. 말풍선(있을 때만)
4. 애니메이션(조건 충족 시)

## 애니메이션 원칙

1. 반짝임은 `active/working`에만
2. `waiting_input`은 깜빡임 금지(오탐 방지)
3. 애니메이션은 "실제 런타임 활성 레포"에만 적용

---

## 5. 레이아웃 가이드

## 데스크톱

1. 프로젝트 존 2개를 좌/우 배치
2. 각 존에 팀 베이 + 회의실 1개
3. 복도는 상태를 방해하지 않는 저채도

## 모바일

1. 맵 대신 요약 카드
2. 필수 카드 순서:
   - Claude Code 현재 작업
   - 프로젝트 상태 요약
   - Recent Commands
   - Runtime Telemetry

---

## 6. 정보 계층

## 1차 정보 (항상 보임)

1. 레포별 Active Command 수
2. Claude Code 현재 작업
3. 에이전트 상태

## 2차 정보 (패널)

1. 최근 명령어
2. 최근 커밋
3. Forked agent token 관측치

## 3차 정보 (클릭)

1. 프로필 상세
2. 최근 작업 타임라인

---

## 7. 컴포넌트 스펙

## 좌석 카드 (`seat-bay`)

1. 기본: 저채도 배경 + 얇은 보더
2. grouped: 같은 작업 그룹 색상 보더
3. high-token: active/working + 임계치 초과일 때만

## 회의실 카드 (`meeting-room`)

1. 2인 이상 동일 작업 시 활성
2. 활성 시 task accent 보더
3. 문구는 30자 이내 + ellipsis

## 명령 패널 (`cmd-feed`)

1. 상태 배지: Running/Done/Failed
2. 명령은 모노스페이스
3. 민감값은 마스킹 표시

---

## 8. 접근성 & 가독성

1. 색만으로 상태를 구분하지 않고 텍스트 병행
2. 작은 글씨 최소 `8px`, 주요 정보 `10~12px`
3. 긴 텍스트는 `ellipsis + title tooltip`

---

## 9. 금지 사항

1. 대기 상태를 작업 상태처럼 보이게 하는 애니메이션
2. 배경 장식이 상태 텍스트 대비를 해치는 구성
3. 프로젝트 경계 없는 그룹 컬러 공유

---

## 10. 체크리스트 (디자인 QA)

1. 어떤 레포가 실제 동작 중인지 3초 내 구분 가능한가?

3. 명령/토큰/커밋 패널 우선순위가 명확한가?
4. 모바일에서 핵심 정보가 누락되지 않는가?
